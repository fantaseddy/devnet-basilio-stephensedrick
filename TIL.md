# TIL — Today I Learned

A running log of small things you learn along the way — not a full topic,
just quick notes whenever something clicks or trips you up. Add to this
anytime, not just during formal lessons.

## Sept 23
- Learned that I need to save my files using Ctrl + S before adding, committing, and pushing changes. I forgot to save after cloning, which made me wonder why my changes were not showing up on GitHub.
- Learned that input values are treated as strings by default, so I need to use `int()` when I need the input to be used as a number.
- Learned that `=` assigns a value to a variable, while `==` checks if two values are equal. I mixed them up before, so I need to pay more attention to which one I am using.
- Learned that Python list indexes start at 0 instead of 1. This can be confusing when accessing items in a list, so I need to remember that the first item has index 0.
- Learned that a parameter and an argument are not the same thing. A parameter is the variable written when defining a function, while an argument is the actual value given to the function when calling it.
- Learned that a file-sorting program needs the correct folder path. I got a `FileNotFoundError` because the source folder name/path was wrong, so Python could not find the files I wanted it to sort.
